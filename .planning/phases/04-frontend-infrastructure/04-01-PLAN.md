    **STEP 2a: Add mutation type to mutation-types.js**

    Add the following new mutation type to the contact section of `app/javascript/dashboard/store/mutation-types.js`:

    ```javascript
      SET_CONTACTS_BY_STAGE: 'SET_CONTACTS_BY_STAGE',
    ```

    Place it after `CLEAR_CONTACTS` and before `EDIT_CONTACT` (following the existing order pattern).

    **STEP 2b: Add mutation to mutations.js**

    Add the following mutation to `app/javascript/dashboard/store/modules/contacts/mutations.js`:

    ```javascript
      [types.SET_CONTACTS_BY_STAGE]: ($state, data) => {
        data.forEach(contact => {
          $state.records[contact.id] = {
            ...($state.records[contact.id] || {}),
            ...contact,
          };
          if (!$state.sortOrder.includes(contact.id)) {
            $state.sortOrder.push(contact.id);
          }
        });
      },
    ```

    The `SET_CONTACTS_BY_STAGE` mutation uses the same pattern as `APPEND_CONTACTS` -- it merges contact data into the existing records object (so it does not clear other contacts that may be loaded in the store) and adds new IDs to sortOrder.

    **STEP 2c: Add fetchByStage action to actions.js**

    Add the following action to `app/javascript/dashboard/store/modules/contacts/actions.js`:

    ```javascript
      fetchByStage: async ({ commit }, { stageId, page = 1, sortAttr = 'name' }) => {
        commit(types.SET_CONTACT_UI_FLAG, { isFetching: true });
        try {
          const {
            data: { payload, meta },
          } = await ContactAPI.filter(page, sortAttr, {
            pipeline_stage_id: stageId,
          });
          commit(types.SET_CONTACTS_BY_STAGE, payload);
          commit(types.SET_CONTACT_META, meta);
          commit(types.SET_CONTACT_UI_FLAG, { isFetching: false });
        } catch (error) {
          commit(types.SET_CONTACT_UI_FLAG, { isFetching: false });
        }
      },
    ```

    The action uses `ContactAPI.filter()` passing `{ pipeline_stage_id: stageId }` as the query payload. This matches how Chatwoot's contact filtering API accepts filter criteria. The action commits `SET_CONTACTS_BY_STAGE` (merge, not clear) so it does not disrupt other contacts already in the store.
