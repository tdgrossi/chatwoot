## View Toggle Component

### Placement
In `LeadsIndex.vue` header bar, replacing or augmenting the right side of the header, alongside the existing "Manage Stages" button.

### Layout
```
[<h1 class="text-base font-semibold">Pipeline</h1>]   [<Filter dropdown>] [<View toggle: Kanban | List>]
```

### View Toggle Button Group
**Type:** Adjacent icon buttons sharing a visual group
**Style:** `Button ghost slate` at size `sm` (h-8 w-8), icon-only, placed in a flex container with `rounded-lg overflow-hidden` border container

**Inactive state:** `Button ghost slate` size sm — icon `i-lucide-columns` (Kanban) / `i-lucide-list` (List), color slate
**Active state:** Same button with `bg-n-brand text-white` fill — `bg-n-brand` background, white icon

**Implementation approach:**
- Two `Button` components in a `div` with `gap-0 rounded-lg border border-n-weak overflow-hidden`
- Each button has `rounded-none` to merge into the group
- Active button gets `bg-n-brand text-white` override applied via `class` binding
- Inactive button stays `ghost slate` (text-n-slate-11 hover state)
- `aria-pressed` on each button for accessibility
- `aria-label` on each: "Kanban view", "List view"

### Filter Dropdown (Stage Filter)
**Type:** DropdownMenu.vue with a trigger Button
**Trigger:** `Button outline slate` size sm with icon `i-lucide-filter` and a label showing the active filter name (e.g., "All stages", "Negotiation")
**Placement:** Left of the view toggle group

**Dropdown items structure:**
```js
menuItems = [
  { label: 'All stages', action: 'filter', value: 'all', isSelected: activeFilter === 'all' },
  { label: 'Unassigned', action: 'filter', value: 'unassigned', isSelected: activeFilter === 'unassigned' },
  ...orderedStages.map(stage => ({
    label: stage.name,
    action: 'filter',
    value: stage.id,
    isSelected: activeFilter === stage.id,
  }))
]
```

**Behavior:**
- Clicking an item selects it, closes dropdown, updates filtered list
- `isSelected: true` shows `bg-n-alpha-1 dark:bg-n-solid-active` on the item (from DropdownMenu default styles)
- Dropdown closes on item click via `emit('action', ...)` + local close

Use named slots `header-{index}` for custom headers, `row` for custom rows.

### Table Row Styles
- `border-b border-n-weak` — divider between rows
- `hover:bg-n-alpha-2` — row hover highlight
- `cursor-pointer` — indicates clickability
- `transition-colors` — smooth hover transition
- Cell padding: `py-3 px-4` (12px vertical, 16px horizontal)

### Sort Behavior (D-07)
- Default sort: `name` ascending
- Click column header to sort; first click = asc, second = desc, third = back to default
- Sort state: `{ key: string, direction: 'asc' | 'desc' | null }`
- Sortable columns show a sort icon (chevron up/down) in header
- Non-sortable columns (Phone) show no icon

### Date Formatting
Use Chatwoot's existing date formatting helper. Fallback:
- `last_activity_at` / `created_at`: format as relative time if < 7 days, else as `MMM D, YYYY`

## Stage Filter Logic

### Filter Options (D-04)
```js
const stageFilterOptions = computed(() => [
  { key: 'all',        label: 'All stages',  value: 'all' },
  { key: 'unassigned', label: 'Unassigned', value: null },
  ...orderedStages.value.map(stage => ({
    key: stage.id,
    label: stage.name,
    value: stage.id,
  })),
])
```

### Filtering Logic
```js
const activeFilter = ref('all'); // 'all' | 'unassigned' | stageId

const filteredContacts = computed(() => {
  const all = Object.values(contactsMap.value);
  if (activeFilter.value === 'all') return all;
  if (activeFilter.value === 'unassigned') {
    return all.filter(c => !c.pipeline_stage_id);
  }
  return all.filter(c => String(c.pipeline_stage_id) === String(activeFilter.value));
});
```

## Interaction Contract

### View Toggle Flow
1. User clicks Kanban/List button
2. `setView()` updates localStorage + `activeView` ref
3. `v-if="activeView === 'kanban'"` conditionally renders KanbanBoard
4. `v-else-if="activeView === 'list'"` renders ContactsTable
5. Selected view persists across page reloads

### Stage Filter Flow
1. User clicks filter button in header
2. DropdownMenu opens (rendered inline in header, `position: absolute`)
3. User selects an option
4. `activeFilter` ref updated; `filteredContacts` computed re-evaluates
5. Dropdown closes automatically on selection

### Sort Flow
1. User clicks sortable column header
2. Sort state toggles: null -> asc -> desc -> null (column-specific)
3. `filteredContacts` computed applies sort to current filtered set
4. Sort icon in header updates to reflect direction

### Row Click Flow
1. User clicks a table row
2. `handleRowClick(contact)` called
3. Currently logs to console (Phase 8 will open sidebar)
